# Bundled typefaces

Latin subsets, self-hosted so the strict `font-src 'self'` policy holds and no third-party font request leaks page visits.

| File | Family | Licence |
|---|---|---|
| `public-sans-var.woff2` | Public Sans (variable 400–700), USWDS | SIL Open Font License 1.1 |
| `source-serif-4-var.woff2` | Source Serif 4 (variable 400–600, optical size), Adobe | SIL Open Font License 1.1 |
| `plex-mono-400.woff2`, `plex-mono-500.woff2` | IBM Plex Mono | SIL Open Font License 1.1 |
