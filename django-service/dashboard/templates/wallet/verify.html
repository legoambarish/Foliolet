Where the pins come from

The pins are prefilled from configuration that the operator of this verifier page provisioned separately. They are never read from the proof or from the {{ product_label }} API. If you have your own deployment record, replace them. A missing or malformed pin makes the check fail closed.

Offline verification

The downloaded proof can be checked with the standalone Node verifier. That needs no account, no service and no original file. A downloaded proof can be copied, so link expiry only stops new releases.

What this can't show

{{ product_label }} is a custodial commitment system. A passing independent check establishes membership, signature and current pinned chain state. It does not establish that the holder approved this release if the platform itself is malicious.
