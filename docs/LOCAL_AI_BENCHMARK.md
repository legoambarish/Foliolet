# Measured local AI behavior

Host: Windows, NVIDIA RTX 4060 Laptop GPU with 8188 MiB VRAM, Ollama 0.40.3. Measurements used explicitly fake fixture text and a synthetic image on 13 October 2026. They do not establish a general accuracy rate, legal competence or authentic issuer extraction.

Text: qwen3:4b, Q4_K_M, 2,497,293,931 bytes, digest `359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7`. Temperature 0, context 8192, prediction limit 768, thinking disabled. Six prompts: fee, refund, notice, unsupported bank balance, hostile instruction and clause review. Five outputs had exact quotations; one fabricated a fee quotation and must be rejected. Even a correct quotation can accompany an unsupported inference, so exact grounding is necessary but insufficient for correctness.

First uncached text request: 90.306 seconds total, 86.006 seconds to first token, 50.722 seconds load, 13.95 generated tokens/second. Five subsequent requests: 0.858, 0.756, 0.806, 2.536 and 1.889 seconds total, approximately 74.8 to 76.3 tokens/second. GPU memory in the captured inventory was 4491 MiB including other GPU users, not a model-only allocation. A later warmed process restart loaded qwen in 3.893 seconds; this does not replace the measured uncached cold-start result.

Vision: gemma3:4b, Q4_K_M including projector, 3,350,272,403 bytes, digest `68ceab7e468a31c988b44d5a4984a0e21f58c4f7158c6ce29c1804babac38df7`. One synthetic 1024x768 image contained TEST LEASE, INR 25000 and 60 days; all expected fields were read correctly. Total 64.815 seconds, first token 64.118, load 35.823, 75.26 tokens/second, captured GPU inventory 4473 MiB. Vision UI integration was cut because this one fixture does not justify a general scanned-document capability, and switching/cold start harms the demonstration. No image extraction enters credential authority.

Raw measurements remain ignored under `.bridge-data/artifacts/text-benchmark.json` and `vision-benchmark.json`. Reproduce with bundled Python containing Pillow and requests: `python tools/benchmark-local-ai.py`, then `python tools/benchmark-local-ai.py --vision`. The project venv requires Pillow for the optional vision benchmark. Core product use does not require Pillow or a vision model.

Download after starting managed Ollama: `./.venv/Scripts/python.exe tools/pull-model.py qwen3:4b` and optionally `gemma3:4b`. Run `tools/warm-models.py`; it warms vision first and leaves qwen loaded last under the one-model budget. Ollama cloud behavior is disabled by `OLLAMA_NO_CLOUD=true`. Spring accepts only configured loopback/host-local HTTP endpoints and the two local model names, and the legacy external AI path is disabled by default.

Spring does not expose unchecked token text. It streams lifecycle events and releases an answer only after quote/schema validation. Source passages remain available when generation fails or is rejected. Actual Spring acceptance status and latency are derived in `verification-results.json`; do not replace rejected-output evidence with an assumed success. No AI output is part of a verification package, holder signature, decision policy or source-truth judgment.
